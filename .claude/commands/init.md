Este es un proyecto nuevo basado en el template JDG. Hacé lo siguiente:

1. Pedime el **nombre del proyecto** y una **descripción de una línea**
2. Pedime si es un proyecto **propio (JDG)** o para un **cliente** (y el nombre del cliente)
3. Actualizá `CLAUDE.md` con el nombre, descripción, fecha de inicio y cliente
4. Actualizá `docs/CONTEXTO.md` con la descripción inicial
5. Actualizá `docs/BITACORA.md` con la primera entrada de sesión
6. Si es para cliente, creá `marca/cliente/` con los archivos base copiados de `marca/jdg/`
7. Mostrame un resumen de lo configurado y preguntame cuál es la primera tarea del proyecto

NO empieces a codear nada. Solo configurá el proyecto y esperá instrucciones.
