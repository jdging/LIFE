Setup · Compras + Recetario

LIFE · Lista del Super + Catálogo de Recetas · Guía de configuración AppSheet

Este tutorial cubre la configuración de la app AppSheet para los módulos Compras y Recetario. Ambos usan la misma app y la misma Google Sheet (hojas distintas), siguiendo la decisión DEC-B3.

Prerequisitos: las hojas de la Sheet ya deben existir antes de configurar AppSheet. Si no corriste los scripts de setup, hacelo primero: setupComprasSheet() + setupComprasTrigger() (ya hecho), y setupRecetarioSheets() + setupRecetarioTriggers() (C-MANUAL-1).

1 Configuración base de la app AppSheet

Si ya tenés la app creada para Compras, saltá al paso de seguridad más abajo. Si empezás desde cero:

  1. Andá a appsheet.com e iniciá sesión con tu cuenta Google.
  2. Hacé clic en Create > App > Start with your own data.
  3. Seleccioná la Google Sheet de Compras+Recetario (la que tiene las hojas ListaCompras, Recetas e Ingredientes).
  4. AppSheet va a detectar las hojas automáticamente. Nombrá la app "LIFE Compras" o similar.

Configurar seguridad (obligatorio para el iframe):

  1. En el panel de la app, andá a Security > Require Sign-in.
  2. Desactivarlo completamente (toggle en OFF).
  3. Guardá y publicá (Save > Deploy).
Importante: si Require Sign-in está activado, el iframe en los dashboards va a mostrar un error CSP frame-ancestors y la app no va a cargar. Desactivarlo es obligatorio para embeber AppSheet en GitHub Pages.

Pegar la URL en los dashboards:

Una vez publicada la app, copiá la URL de la forma https://www.appsheet.com/start/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx y pegala en dos lugares:

ArchivoConstante
src/compras/index.html const APPSHEET_URL = 'https://www.appsheet.com/start/...';
src/recetario/index.html const APPSHEET_URL = 'https://www.appsheet.com/start/...'; (misma URL)

2 Vista "Nueva compra" — hoja ListaCompras

Esta vista permite agregar ítems a la lista del super. AppSheet genera automáticamente una vista de formulario para cada tabla — vamos a ajustar qué campos se muestran.

En el panel de AppSheet, andá a Views y encontrá la vista generada para ListaCompras. Configurala como formulario de entrada:

  1. Renombrala a "Nueva compra".
  2. Tipo de vista: Form.

Campos visibles (Show = ON):

nombreTextCampo principal — obligatorio
cantidadDecimalDefault: 1
unidadEnumOpciones: u, kg, g, l, ml
categoriaEnumOpciones: Verduras, Carnes, Lacteos, Panaderia, Almacen, Bebidas, Limpieza, Otro
urgenteYes/NoMostrar como checkbox destacado

Campos ocultos (Show = OFF):

CampoValor por defecto
idAuto-generado por trigger Apps Script (COMP-XXXXX)
estado"pendiente" (hardcodeado)

Tip urgente: para destacar el campo urgente, en AppSheet podés configurarlo con el ícono de alerta (⚠) o cambiarle el label a "Urgente ⚡". El dashboard lo muestra con un badge naranja cuando está en TRUE.

3 Vista "Nueva receta" — hoja Recetas

Esta vista permite cargar el encabezado de una receta. Los ingredientes se cargan por separado en la Sección 4, vinculando con el ID de la receta.

  1. En Views, creá una vista nueva para la tabla Recetas.
  2. Tipo: Form. Nombre: "Nueva receta".

Campos visibles (Show = ON):

categoriaEnumOpciones: Desayuno, Almuerzo, Cena, Merienda, Postre, Otro
instruccionesLongTextOpcional — texto libre de preparación

CampoValor por defecto

4 Vista "Nuevo ingrediente" — hoja Ingredientes

Esta vista se usa para cargar los ingredientes de una receta existente. El campo receta_id debe ser un dropdown que liste las recetas cargadas — AppSheet lo hace automáticamente si configurás la referencia correctamente.

  1. En Views, creá una vista nueva para la tabla Ingredientes.
  2. Tipo: Form. Nombre: "Nuevo ingrediente".

Configurar receta_id como dropdown (paso clave):

  1. Andá a Data > Tables > Ingredientes > Columns.
  2. Encontrá la columna receta_id. Cambiá su tipo a Ref.
  3. En "Referenced table", seleccioná Recetas.
  4. En "Label column", seleccioná nombre.
  5. Guardá — ahora el campo muestra un dropdown con los nombres de las recetas pero guarda el ID en la hoja.

Campos visibles (Show = ON):

CampoTipoNotas
receta_idRef → RecetasDropdown con nombres. Obligatorio.
nombreTextNombre del ingrediente (ej: "Harina", "Tomate")
cantidadDecimalCantidad para las porciones base de la receta
unidadEnumOpciones: u, kg, g, l, ml, cdita, cda, taza
Nota sobre unidades: cdita, cda y taza son válidas en Ingredientes pero no existen en Compras. Al usar el botón "Agregar al super" en el dashboard de Recetario, estas unidades se convierten automáticamente a u.

✓ Checklist final

Antes de considerar el setup completo, verificá cada ítem en orden:

  • Script setupComprasSheet() ejecutado en Apps Script de la Sheet Compras+Recetario
  • Script setupComprasTrigger() ejecutado (trigger auto-ID COMP-XXXXX activo)
  • Script setupRecetarioSheets() ejecutado (hojas Recetas e Ingredientes creadas)
  • Script setupRecetarioTriggers() ejecutado (triggers RECETA-XXXXX e ING-XXXXX activos)
  • compras-api.js deployado como Web App (Execute as: Me / Who has access: Anyone) — NEW deployment
  • URL de compras-api.js pegada en const API_URL de src/compras/index.html
  • recetario-api.js deployado como Web App (Execute as: Me / Who has access: Anyone) — NEW deployment
  • URL de recetario-api.js pegada en const RECETARIO_API_URL de src/recetario/index.html
  • App AppSheet creada y conectada a la Sheet Compras+Recetario
  • Security → Require Sign-in desactivado en la app AppSheet
  • Vista "Nueva compra" configurada para hoja ListaCompras (campos ocultos con defaults)
  • Vista "Nueva receta" configurada para hoja Recetas (campos ocultos con defaults)
  • Vista "Nuevo ingrediente" configurada para hoja Ingredientes (receta_id como Ref → Recetas)
  • URL de AppSheet pegada en const APPSHEET_URL de src/compras/index.html
  • URL de AppSheet pegada en const APPSHEET_URL de src/recetario/index.html
  • App publicada (Deploy) con los últimos cambios
  • Verificar que el drawer del + cargue AppSheet en Compras sin error
  • Verificar que el drawer del + cargue AppSheet en Recetario sin error
  • Cargar una receta de prueba y verificar que aparece en el dashboard de Recetario
  • Probar "Agregar al super" desde Recetario y verificar que los ítems aparecen en Compras
Recordatorio de re-deploy: cualquier cambio al código de un archivo .js en Apps Script requiere crear un NEW deployment — no editar el existente. La URL cambia con cada nuevo deployment.
